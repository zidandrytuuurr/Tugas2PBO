 Tugas PBO Sesi 2

1. Pengertian Class dan Object

Class adalah blueprint atau cetakan untuk membuat object yang berisi atribut dan method.
Object adalah hasil instansiasi dari class.

2. Jenis-jenis Method

1. Method void (tanpa return) → tidak mengembalikan nilai
2. Method return → mengembalikan nilai
3. Method dengan parameter → menerima input
4. Method tanpa parameter → tidak menerima input

3. Penjelasan Kode

1. Class → public class Komputer
2. Atribut → jenis_komputer, merk
3. Setter → setDataKomputer()
4. Getter → getJenis()
5. Getter → getMerk()
6. Object → Komputer mykom = new Komputer()
7. Set data → mykom.setDataKomputer("LAPTOP", "MACBOOK")
8. Output → System.out.println()
